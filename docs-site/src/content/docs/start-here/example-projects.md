## What this does

The packaged examples demonstrate branching, attempts, selections, review
states, and handoffs with intentionally public synthetic assets.

## How to use them

Start Lineage with a verified named profile, open the project chooser, and load
an example project. Use it to practice:

- following a branch from its root;
- opening attempt history and changing the current attempt;
- selecting a next-variation input;
- reading a handoff packet; and
- comparing open and released agent claims.

Examples are learning fixtures, not production templates. Never copy a live
SQLite database or private media into the repository to create a demo.
