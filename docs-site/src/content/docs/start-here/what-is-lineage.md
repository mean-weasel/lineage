## What this does

Lineage gives humans and agents one visual record of creative work. It stores
assets, their relationships, prompts, attempts, selections, reviews, and
handoffs so a later session can continue from the same state.

## When to use it

Use Lineage when visual work branches, gets re-generated, passes through review,
or moves between agent sessions. It is especially useful when chat history
alone is no longer a reliable representation of the work.

## How it works

A project contains assets. A workspace focuses a particular root and its
lineage. Branches add visible alternatives; re-rolls add attempts to the same
asset. Human selections and annotations become structured context for the next
agent handoff.

Lineage is local-first. Runtime channels and named profiles make the code,
database, media root, and service identity explicit.

## Common misunderstandings

- Lineage does not replace an image model or agent chat.
- The Agents view is not a list of Codex sessions.
- A re-roll is not a branch.
- The current attempt does not erase earlier attempts.
