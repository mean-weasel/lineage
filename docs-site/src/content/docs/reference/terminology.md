---
title: Terminology
description: Use consistent names for Lineage concepts, workflows, runtime identity, and integrations.
---

## Creative state

- **Asset** — a creative item with stable identity.
- **Attempt** — one execution attached to an asset.
- **Branch** — a new child asset and visible edge.
- **Re-roll** — a new attempt on the same asset.
- **Selection** — explicit input for the next variation.
- **Workspace** — a saved focus on a project root and its lineage.

## Coordination

- **Claim** — temporary bounded ownership for a mutation.
- **Handoff** — durable context for another agent session.
- **Receipt** — proof of a planned or completed operation.

## Runtime

- **Channel** — stable, preview, or checkout-only development code.
- **Profile** — the named identity binding code, database, media root,
  environment, and service origin.
