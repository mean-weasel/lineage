---
title: Restore an earlier attempt
description: Make a previous attempt current without deleting later history or creating a new branch.
---

## When to use it

Restore an earlier attempt when a re-roll is weaker than a previous execution
but the asset’s identity and graph position should remain unchanged.

## Step-by-step workflow

1. Open the asset details or attempt-history view.
2. Compare previews, prompts, and timestamps.
3. Choose the intended earlier attempt.
4. Confirm it as the current attempt.
5. Verify the canvas and any active selection.
6. Add a note when the restoration changes the next planned operation.

Later attempts remain in history. To create a separate visible direction, use a
branch instead.
