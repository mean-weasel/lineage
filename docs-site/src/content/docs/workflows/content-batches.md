## What this does

Content batches group related posts, targets, media candidates, review states,
and scheduling intent. They are useful when one creative lineage feeds several
channels or campaign moments.

## Step-by-step workflow

1. Import a synthetic or approved batch definition.
2. Review each post’s body, call to action, target, and media candidates.
3. Resolve missing or ambiguous assets.
4. Mark the reviewed target.
5. Prepare an agent or scheduler handoff.
6. Record scheduling or posting state only after the external action is known.

Buffer integration currently validates dry-run payloads. It does not publish
live. See [Social scheduling](../integrations/social-scheduling).
